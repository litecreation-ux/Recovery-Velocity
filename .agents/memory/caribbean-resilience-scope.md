---
name: Caribbean resilience scope
description: Product boundary for the country-risk dashboard and local planning maps.
---

The country-risk dashboard is intentionally limited to Caribbean countries for this release. Jamaica is the only location with verified parish-level operational workflows. Other Caribbean maps use clearly labelled, selectable reference cities and only country-level source data until a verified local feed is onboarded.

**Why:** The user explicitly requested a Caribbean-only focus and local resilience values must not be fabricated from national data.

**How to apply:** Do not add non-Caribbean countries or imply local infrastructure, finance, health, or continuity coverage outside Jamaica without an authoritative, documented source and a transparent data boundary.
